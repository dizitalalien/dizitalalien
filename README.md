# 👽 Dizital Alien LLP

Welcome to the official GitHub organization for **Dizital Alien LLP** — a technology venture based in Raipur, Chhattisgarh. We specialize in highly scalable IT solutions, AI/ML orchestration, data engineering, and hyper-local service aggregators.

---

## 🚀 Our Flagship Projects

### 1. LaundryGogo (Trenzzo Laundry)
Chhattisgarh’s premier on-demand, hyper-local garment care ecosystem. We provide the technology layer that transforms traditional independent laundromats into tech-enabled micro-entrepreneurs.
* **Tech Stack:** Cloud Architecture (AWS/GCP), Automated SMS/WhatsApp APIs, Geospatial routing.
* **Impact:** Organizing a highly fragmented local market with an asset-light aggregator model.

### 2. EventSnap (SEPSA)
An AI-powered photo-sharing and facial recognition platform designed to instantly sort and deliver photos for large-scale corporate events, weddings, and town halls.
* **Tech Stack:** Python, DeepFace, OpenCV, Advanced Data Pipelines.

### 3. Enterprise Hospital Management System (HMS)
A robust, end-to-end ERP system designed to digitize healthcare workflows and optimize administrative efficiency (deployed as a prototype for Prathmesh Hospital).
* **Tech Stack:** High-concurrency DBMS, secure healthcare data compliance architectures.
